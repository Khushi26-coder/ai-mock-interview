
# 🤖 AI Mock Interview

🚀 A simple AI Mock Interview web application built using **React.js** and **Node.js**.
This project helps users practice interview questions with a timer and receive instant feedback.

---

## 📌 Features

* 🎯 Multiple interview questions
* ⏱️ 60-second timer for each question
* 💬 Instant feedback system
* 📝 Answer tracking
* 📊 Interview summary at the end

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js + Express
* Styling: CSS

## 🚀 How to Run Project

### 1️⃣ Clone Repository

git clone https://github.com/Khushi26-coder/ai-mock-interview.git

### 2️⃣ Go to Project Folder

cd ai-mock-interview

### 3️⃣ Install Dependencies

👉 Frontend:
cd frontend
npm install

👉 Backend:
cd backend
npm install

---

### 4️⃣ Run the Project

👉 Start backend:
cd backend
node server.js

👉 Start frontend:
cd frontend
npm start

---

## 🌐 Output

👉 Frontend runs on:

👉 Backend runs on:
